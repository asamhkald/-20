# قائمة أمن ما قبل الإنتاج

- [ ] RLS مفعّل ومختبر على كل جدول tenant-scoped.
- [ ] لا يوجد service_role في العميل أو المستودع.
- [ ] التحقق من العضوية والصلاحية يتم على الخادم.
- [ ] اختبار cross-tenant read/write لكل دور.
- [ ] إدارة جلسات وتسجيل خروج وانتهاء صلاحية.
- [ ] حماية من CSRF/XSS/SQL injection حسب مسارات التطبيق.
- [ ] سجل تدقيق غير قابل للتعديل من مستخدم الأعمال.
- [ ] مفاتيح idempotency فريدة ومقيدة بالمستأجر والعملية.
- [ ] نسخ احتياطي مشفر واختبار استعادة دوري.
- [ ] سياسة احتفاظ وحذف وتصدير بيانات موثقة.
- [ ] أسرار الإنتاج في مدير أسرار، لا في ملفات الواجهة.
- [ ] مراقبة أخطاء وتنبيهات دون تسجيل بيانات حساسة.
- [ ] اختبار اختراق ومراجعة صلاحيات قبل الإطلاق.

- [ ] قيد عكسي واحد كحد أقصى لكل قيد أصلي، مع قيد UNIQUE في قاعدة البيانات واختبار التزامن.
- [ ] مفاتيح tenant وbranch موجودة في كل العلاقات الحساسة وتُفحص ضد العضوية الفعلية.
- [ ] القيد المرحّل مجمّد في طبقة المجال ومحمي بقيود قاعدة البيانات من UPDATE/DELETE.
- [ ] اختبارات عزل الصلاحيات تعمل على قاعدة staging فعلية، لا على واجهة المستخدم فقط.
