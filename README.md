# Sama Business — Foundation Kit

نسخة تأسيسية مطوّرة لمشروع Sama Business وفق القرارات المعتمدة:
- الاسم: Sama Business
- السوق: Global
- المعمارية: Modular
- التصميم: Premium
- التنفيذ: Phased
- الأولوية: Foundation (المحاسبة، قاعدة البيانات، الأمان)

## مهم جداً بشأن البيانات
- الأرشيف الأصلي محفوظ دون تعديل داخل `legacy/شام-محاسبه-original.zip`.
- هذا المستودع التأسيسي لا يتصل بقاعدة بيانات الإنتاج تلقائياً.
- لا توجد ترحيلات SQL تغيّر جداولك الحالية.
- لا تستورد بيانات الإنتاج ولا تشغّل أي كتابة على Supabase قبل استلام مخطط القاعدة وسياسات RLS والنسخة الاحتياطية.
- ملفات `.env` غير مرفقة. انسخ `.env.example` إلى `.env.local` عند بدء إعداد بيئة تطوير منفصلة.

## المتطلبات
- Node.js 20+
- npm 10+

## التشغيل المحلي
```bash
npm install
npm run dev
```

## الاختبارات
```bash
npm test
npm run typecheck
npm run build
```

## الهيكل
- `src/core`: منطق المجال المستقل، المال الدقيق، الحسابات، الفترات المالية، القيود والصلاحيات.
- `src/modules`: حدود مستقلة لكل وحدة أعمال؛ الوحدات غير المذكور تنفيذها في سجل الحالة ما زالت ضمن خارطة الطريق.
- `tests`: اختبارات قواعد النواة المحاسبية والأمان.
- `src/lib`: تكاملات خارجية، ومنها Supabase بعد الإعداد.
- `docs`: المواصفات وقرارات التصميم وخطة ترحيل آمنة.
- `legacy`: الأرشيف الأصلي كما وصل، للرجوع والمقارنة.

## نطاق هذه الحزمة
هذه **قاعدة تأسيسية قابلة للتطوير** وليست ERP مكتمل الوظائف، ولا تحتوي على ترحيل تلقائي أو اتصال إنتاجي. راجع `docs/IMPLEMENTATION-STATUS.md` لمعرفة ما تم تنفيذه فعلياً وما لا يزال غير متصل. لا تنفذ أي SQL على قاعدة الإنتاج.

## سجل التسليم
- `docs/DATABASE-CONTRACT.md`: متطلبات تكامل قاعدة البيانات دون أي أوامر تغيير إنتاجية.
- `docs/IMPLEMENTATION-STATUS.md`: سجل التنفيذ والقيود الحالية.
- `docs/SAFE-MIGRATION.md`: بوابات الحفاظ على البيانات قبل الترحيل.

## التشغيل المتوازي والنشر التلقائي على GitHub Pages
- تم إدراج نسختك السحابية العاملة بالكامل داخل `public/app/` (`index.html` و`manifest.json` و`sw.js` و`icon.svg`)، مع إبقاء الأرشيف الأصلي كما هو دون أي تعديل داخل `legacy/شام-محاسبه-original.zip`.
- تفتح واجهة **Sama Business** الرئيسية على الرابط الأساسي وتوفر أزرار دخول مباشر إلى برنامج المحاسبة السحابي العامل على المسار `./app/index.html`.
- تم تضمين ملف النشر التلقائي `.github/workflows/deploy.yml`؛ يكفي رفع محتويات المجلد `sama-business-foundation` إلى جذر مستودعك في GitHub ثم اختيار **GitHub Actions** من `Settings → Pages → Source` ليتم البناء والاختبار والنشر تلقائياً.
